Continuous Maps Preserve Nearness

Two thermometers measure the same room but use different scales. When real temperatures are close together, do the two thermometers always read nearby numbers? How do you know that switching from Celsius to Fahrenheit doesn't secretly create jumps between nearby temperatures?

Naive Picture

A map is continuous if you can draw its graph without lifting your pencil from the paper—a smooth, unbroken line or curve.

Why It Fails

Many of the spaces in this course have no single flat graph paper to draw on. A coordinate chart on a sphere cannot flatten the whole sphere. You need a way to talk about continuity that doesn't depend on pencil-and-paper.

Mathematical Object

A continuous map is a function between two spaces where the inverse image of any open region—any set you'd test with a neighborhood—stays open in the starting space. If A maps to B, the preimage of an open test-region in B is an open test-region in A.

Operation

To check if a map is continuous: pick any open test-region in the target space, pull it backward through the map, and ask whether what you get back is open in the starting space. If that always works, the map is continuous.

Why It Matters

Spacetime descriptions come from many observers with different coordinates. A continuous map ensures that when two events are close in one observer's language, they remain close in another observer's language—no hidden jumps appear from coordinate switching.

What Breaks Without It

If maps need not preserve openness, then coordinate changes could create artificial discontinuities: regions that were connected could appear to tear. A field could look smooth in one chart but split artificially in another.

Mini Example

A car's speedometer converts engine speed (revolutions per minute) to a needle position (degrees of arc). Near 3000 rpm, small changes in true speed produce small changes in needle angle. The map from speed to needle is continuous: if you pick an open range of needle positions—say, 30° to 40°—the speeds that map into it form an open interval, like 2900 to 3100 rpm. No sudden jumps hide the mapping.

Common Confusion

Continuity does not mean the map is identical to the identity, or that nothing changes. It permits wild stretching and bending. It only forbids tearing the neighborhood relation—breaking the link between close inputs and close outputs.

First-Principles Walkthrough

Imagine you're tracking temperature in a room using two different devices: an old mercury thermometer and a digital one. Close temperatures in the physical world should give close readings on both instruments. That's the felt problem—we want a guarantee that nearness is preserved across different descriptions. The naive idea is that a continuous map is one whose graph you can draw without lifting your pencil. But in this course, we work with spaces that don't sit flat on paper. A sphere cannot be flattened to a plane without tearing. A manifold—the mathematical surface describing spacetime—is built from overlapping patches, not a single sheet. So we need a notion of continuity that lives in the spaces themselves, without reference to any external graph paper. The answer is to work backward: a map is continuous if whenever you pick an open neighborhood (a test region) in the target space, pulling that region back through the map gives you an open neighborhood in the starting space. This works for any spaces, flat or curved, local or global. The operation is simple: test with open sets. The payoff is huge. In relativity, different observers describe the same events using different coordinates. Continuity guarantees that if two observers agree that two events are close, all observers who switch to new coordinate descriptions will still agree they're close. Without this protection, changing coordinates could create false discontinuities—make nearby events appear to jump. That would poison the entire theory.

Mathematical Detail In Plain Language

Let f be a map from space X to space Y. The open set U sits in Y. The inverse image or preimage of U under f, written f⁻¹(U), is the set of all points in X that map into U. The definition says: f is continuous if and only if for every open set U in Y, the set f⁻¹(U) is open in X. Why does this preserve nearness? Open sets are the language of neighborhoods. If you have an open set U in Y, any point in U has a neighborhood wholly within U. When you pull U back to X, getting f⁻¹(U), you're asking: which points in X have all their images close together in U? If f⁻¹(U) is open, then every point in f⁻¹(U) has a neighborhood in X that also maps into U. That's precisely the guarantee that nearby inputs stay mapped to nearby outputs.

Why This Cannot Be Skipped

Without continuity, differential geometry—the branch of mathematics that describes smooth curved spaces—cannot exist. You lose the ability to properly define manifolds, the curved spaces that general relativity rests on. Calculus becomes meaningless: derivatives and integrals require you to take arbitrarily small steps and compare nearby values consistently. Every geometric operation—measuring curvature, connecting vectors at different points, writing field equations—collapses entirely. The entire mathematical infrastructure that lets physicists treat spacetime as a smooth, interconnected whole disintegrates into disconnected fragments.

Where It Sits In The Course

Open sets (from the previous page) are the tool; continuity is how maps respect them. The next pages—Topology and Continuity, Charts and Atlases—build on this to talk about smooth changes between different local views of the same space.

Connective Thread

Continuity bridges the abstract language of open sets to the concrete behavior of actual maps. Every coordinate chart, every field equation, every change of observer relies on this single guarantee: nearby points in one description remain nearby in every other description, by mathematical necessity, not by accident.

Tutorial 1: Topology

Pressure test: Use open sets as the test of nearness before any ruler has been introduced. The tutorial pressure is to stop asking for distance and instead ask whether a proposed region gives each point enough local room, then whether a map sends open-set tests back to open-set tests.

Why it changes this concept: This changes the concept page from a definition of topology into a habit of restraint. The reader has to earn every later word about smoothness, fields, and light cones by first checking that the weaker idea of nearness is stable.

The selected span is early because that is where the tutorial names the exact hidden move: a set by itself is not enough. The added topology tells us which subsets count as open, and that single choice controls every later statement about continuity. The page therefore reads the tutorial as a drill in earning nearness before using distance.
