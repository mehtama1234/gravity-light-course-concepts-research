Lecture 22: Lecture 22: Black Holes

How does this lecture use Black Holes and Horizons, Event Horizon As Causal Boundary to move the course from everyday geometric intuition toward a usable theory of gravity and light?

Family Role

Solve evolution and global shape: The course then asks how whole spacetimes behave: how valid initial data evolves, how the universe expands, and how causal boundaries such as horizons are understood.

First-Principles Role

This lecture defines black holes through causal reach. The horizon is understood by what future light signals can do, not by a material surface picture.

Starting Problem

The black-hole lecture has to replace escape-speed folklore with causal structure. A black hole is not best understood as a dark surface sitting in space. The defining issue is whether future-directed light from an event can ever reach distant outside observers. That makes the horizon a boundary in spacetime signaling, not a material wall. The lecture therefore tests black-hole ideas by asking what light can do.

Mathematical Turn

The mathematical turn is to use null paths and causal reach to define the black-hole region. At each event, the metric gives the future light directions. Following those directions tells whether a signal can escape outward. The event horizon is the boundary of the no-escape set. This also explains why coordinates must be handled carefully: a bad-looking component can mark a poor chart rather than a true spacetime obstruction.

Worked Path Through The Lecture

  1. Start at an event and use the metric to identify future light directions.
  2. Follow possible future-directed null paths from that event through the spacetime geometry.
  3. Ask whether any of those paths can reach distant outside observers.
  4. Define the horizon as the boundary between escape and no escape.

Objects To Track

  • An event horizon is a boundary in spacetime's causal structure; Penrose diagrams compress infinities to show which events can influence which others.
  • An event horizon is the boundary separating events that can send light to distant outside observers from events that cannot.

Linked Concepts

Black Holes and Horizons

Throw a ball upward from Earth. Make it go fast enough—11 kilometers per second—and it never comes back. Now imagine a much heavier object: a collapsed star so dense and tightly packed that the escape speed becomes the speed of light itself. Nothing can go faster than light. So nothing can escape. The question is simple: where exactly does this prison boundary lie?

Object: An event horizon is the surface in spacetime where light rays stop being able to escape outward. Spacetime is the 4D shape made of all moments and locations combined. A one-way membrane in that spacetime, the horizon marks the point beyond which no light cone from inside ever reaches the distant universe. You find it by asking: from this location, do light rays shot forward in time ever reach far away, or do they always curve back inward?

Operation: To find where a horizon is, trace the paths that light takes through the curved spacetime around a black hole. Light travels along paths shaped by that curvature, not straight lines. Start from a suspected boundary and follow the light rays forward in time. If they curve back and fall inward, you have found the boundary. If they escape outward, you have not gone far enough in. The horizon is the surface where light rays neither escape nor fall back—they sit on the edge.

Event Horizon As Causal Boundary

Picture a river flowing over a waterfall. At some point downstream, no swimmer can send a message upstream to someone sitting before the falls—not because a wall blocks them, but because the water's motion forbids it. A light beam behaves the same way near a black hole: past a certain boundary, light cannot travel outward to reach observers who are far away. We need a clear way to define that boundary using what signals are and are not allowed to do.

Object: An event horizon divides spacetime into two regions. In one region, light rays starting from an event can travel outward and eventually reach distant observers. In the other, no light ray starting from an event will ever reach those distant observers, no matter which direction it travels. The horizon itself is the sharp line between these two regions. To find it, physicists trace light rays forward through time from every event and ask: does this ray reach infinity? The boundary of the set of events whose rays reach infinity is the event horizon.

Operation: To locate an event horizon: (1) Set up a spacetime geometry using Einstein's equations for a given mass distribution (for example, a black hole). (2) From each event (a point in spacetime), construct all possible light-ray paths pointing into the future. (3) For each ray, check whether it escapes to infinity or remains confined. (4) The boundary where rays change from escaping to confined is the event horizon.
