Lecture 03: Lecture 3: Multilinear Algebra

How does this lecture use Multilinear Algebra, Dual Vectors Measure Directions, Tensor Components Versus The Object to move the course from everyday geometric intuition toward a usable theory of gravity and light?

Family Role

Build space before measuring it: A theory of gravity cannot begin by assuming a fixed grid, fixed rulers, or a surrounding room. These lectures build the minimum language needed to speak about places, change, and physical quantities before distance has been granted.

First-Principles Role

This lecture trains the reader to read mathematical quantities by their slots and actions rather than by one component table. That discipline is what later lets metric, curvature, and stress-energy remain meaningful across observers.

Starting Problem

Multilinear algebra enters because relativity cannot use loose lists of numbers as physical quantities. A vector points, a covector measures a vector, and a tensor may accept several directions or measuring rules at once. If those jobs are blurred, Einstein's equation later looks like two complicated arrays being equated. This lecture builds the habit of asking what slots an object has before asking what its components look like in a chosen basis.

Mathematical Turn

The mathematical turn is to treat tensors as rules first and components second. A basis turns a tensor into a display of numbers, but the object is the slot rule that tells what can be fed into it and how the answer changes under a basis change. Contraction, pairing, and basis transformation are not notation games. They are the checks that keep metric, curvature, and stress-energy from depending on one observer's bookkeeping.

Worked Path Through The Lecture

  1. Start with the need for quantities that keep meaning after coordinates or bases change.
  2. Ask what inputs the object accepts: vectors, covectors, or several slots at once.
  3. Choose a basis only to display the object as components.
  4. Change basis and verify that the slot rule, not the component table, is the stable object.

Objects To Track

  • A tensor is a multilinear rule with specified input slots; it returns a number or another structured object in a way compatible with linear combinations.
  • A dual vector, also called a covector or one-form, is a linear measuring rule on vectors.
  • The tensor is the coordinate-independent multilinear rule; components are the rule's numbers after choosing basis vectors and dual basis covectors.

Linked Concepts

Multilinear Algebra

Push a rubber sheet in two directions at once. The sheet pushes back differently than if you pushed it in just one direction. Physics constantly describes how something reacts when you apply multiple directions, slopes, or flows at the same time — and it matters which direction goes with which response.

Object: A multilinear object is a machine. You feed it vectors (arrows showing direction and speed) and covectors (measuring rulers that live in a paired counting space) in specific input slots. Out comes a number or another object. The rule must be linear in each slot: if you double one input arrow, the output doubles; if you add two arrows, the output is two separate outputs added together. The number and type of input slots define what the object is.

Operation: Feed vectors and covectors into the slots in order. Each slot follows linearity, so the calculation stays predictable. You can also merge slots: when a vector slot and a covector slot meet, they can cancel each other out (called contraction), shrinking the number of empty slots left. One multilinear object transforms into another with fewer or different slots.

Dual Vectors Measure Directions

Physics tracks two types of quantities: arrows (velocity, force) show direction and speed of motion, while measuring rules (pressure gradient, light intensity) ask 'how much flows in this direction?' Treating them identically breaks the math because they transform opposite ways when you shift coordinates.

Object: A dual vector (also called a covector or one-form) is a measuring machine built for vectors. Feed it a vector: it produces one number. The machine respects addition and scaling—double the vector input, and the output doubles. When coordinates change, the machine's internal weights shift in a specific opposite way that keeps its output unchanged.

Operation: Apply a dual vector by feeding a vector into it. If the dual vector has components (a₁, a₂, a₃) and the vector is (v₁, v₂, v₃), compute a₁v₁ + a₂v₂ + a₃v₃. The result is one number that stays the same no matter which coordinate system you used to write down those components.

Tensor Components Versus The Object

You measure something with a ruler, and you write down numbers. Your friend measures the same thing with a different ruler, or from a different starting point, or with the ruler rotated. They write down different numbers. Yet you're both measuring the same physical thing. The rule you use to measure stays real and stays the same. How do you write down one rule that produces true results no matter which ruler or starting point you pick?

Object: A tensor is a machine. You feed it arrows (or dual arrows, or a mix), and it outputs a number. No matter which way you choose to measure and write down the arrows—no matter which ruler or starting point—the machine always spits out the same number. The components are what that machine looks like after you've decided on one way to measure and write it down.

Operation: When you switch to a different ruler or starting point, the machine's rule stays the same, but the numbers you see change. To find the new numbers from the old ones, you multiply by a conversion table (and its opposite, once for each input slot). The machine's rule is unchanged; only the recipe written on the page flips.
