Lecture 01: Lecture 1: Topology

How does this lecture use Topology and Continuity, Open Sets As Neighborhood Tests, Continuous Maps Preserve Nearness to move the course from everyday geometric intuition toward a usable theory of gravity and light?

Family Role

Build space before measuring it: A theory of gravity cannot begin by assuming a fixed grid, fixed rulers, or a surrounding room. These lectures build the minimum language needed to speak about places, change, and physical quantities before distance has been granted.

First-Principles Role

This opening lecture gives the course permission to talk about continuity before measurement. Its job is to make nearness precise without distance, so later charts, fields, and light paths do not rest on an unearned ruler.

Starting Problem

Topology is the course's first act of restraint. Before a metric can say how far apart events are, the reader still needs a way to talk about a point being approached, a path not jumping, and a field varying coherently. This lecture teaches that the minimum useful structure is not a ruler but a choice of open sets. That choice says which regions count as local rooms around points. Once that is in place, continuity can be tested without borrowing distance from a geometry the course has not built yet.

Mathematical Turn

The mathematical turn is to replace distance talk with open-set tests. Instead of asking whether two points are a small number of meters apart, ask whether every output room around a value pulls back to an input room around the original point. That inverse-image test is the plain engine behind continuity. It matters because later fields, curves, charts, and light paths all need the promise that nearby inputs do not suddenly land in unrelated output regions.

Worked Path Through The Lecture

  1. Start with the need to describe non-jumping change before any ruler has been introduced.
  2. Choose open sets as local room tests around points before speaking about distance.
  3. Test continuity by pulling every output open set back to the input side.
  4. Use that result as the permission layer for later smooth maps and fields.

Objects To Track

  • A topology is a chosen collection of open sets: enough information to talk about neighborhoods, limits, and continuous maps without yet talking about meters or seconds.
  • An open set is a region that contains a little breathing room around each of its points, stated without choosing units of length.
  • A continuous map is a rule between spaces whose inverse image of any open region is open in the starting space.

Linked Concepts

Topology and Continuity

You need to describe curves that don't jump, and functions that keep nearby points nearby. But before you can say what 'nearby' means using measurements, you need to say which points count as neighbors to each other at all.

Object: A topology is a carefully chosen collection of sets called 'open' sets. A set is open if whenever a point sits inside it, you can draw a neighborhood around that point (another open set) that stays completely inside. The collection itself must satisfy three rules: the whole space and the empty space are both in the collection; any union of open sets is also open; and the intersection of any *finite* number of open sets is also open. This structure lets you talk about which points are neighbors without any ruler or meter.

Operation: To check if a function is continuous, you ask: take any open set in where the function lands (the target space). Now look backward—which starting points map into that target set? If that backward set is also open in the starting space, then the function is continuous. Do this for *every* open set in the target. If it works for all of them, the function is continuous. This test needs no coordinates, no distances, no rulers—just the open sets.

Open Sets As Neighborhood Tests

When you step into a room, you can move a few inches in any direction without walking out the door. Before you have a ruler or a distance formula, you know you have room to move. In the same way, when studying geometry and relativity, the very first thing you need is a way to say which regions give you that kind of breathing room around their points — before you've defined what "distance" even means.

Object: An open set is a subset of space with a special property: around every point inside it, there's a small region (called a neighborhood) that stays completely inside the set. Not infinite, not uncovered — just roomy. The set is "open" because every point has a protected bubble of membership. It's defined by this topological property alone, without reference to distance.

Operation: To test whether a set is open, you pick any point in it and ask: can I find a neighborhood around that point that never leaves the set? If the answer is yes for every single point, the set is open. That test becomes the tool for defining when a function is continuous — a function is continuous if pulling back open sets gives you open sets.

Continuous Maps Preserve Nearness

You measure the temperature of a room two ways: once with a Celsius thermometer, once with a Fahrenheit one. When the real air temperature changes by a tiny bit, do both thermometers show tiny changes, or can one jump wildly while the other creeps? How do you know that converting between temperature scales doesn't secretly hide jumps?

Object: A continuous map is a rule connecting two spaces—call them X and Y—with a special property: if you pick any open set (any "test region" of nearby points) in the target space Y, and trace backward through the map to find which points in X map into it, you always get an open set in X. The backward direction keeps openness intact.

Operation: To check if a map is continuous, do this: pick any open test-region in the space you are mapping to. Trace backward through the map to find all the starting points that land in that test-region. If that backward set is always open in the starting space, the map is continuous. Test with any open region; the rule must hold every time.
