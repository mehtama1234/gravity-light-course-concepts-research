Lecture 18: Lecture 18: Canonical Formulation of GR I

How does this lecture use Canonical Formulation and Constraints, Initial Data Must Satisfy Constraints to move the course from everyday geometric intuition toward a usable theory of gravity and light?

Family Role

Solve evolution and global shape: The course then asks how whole spacetimes behave: how valid initial data evolves, how the universe expands, and how causal boundaries such as horizons are understood.

First-Principles Role

Lecture 18 should be read as a step in the course's construction, not as an isolated topic. The ordinary problem is: The course needs a way to describe spacetime evolution from data on a space-like slice while respecting coordinate freedom. The course needs to explain why not every imagined snapshot of space can be the start of a valid spacetime. The mathematical work to watch is: The operation is decomposing spacetime into space plus time, identifying constraints, and checking how allowed data evolves. The operation is checking the constraint equations before using the data as a lawful starting point. A good writeup should make that operation visible before using later terms from relativity.

Objects To Track

  • The canonical formulation rewrites spacetime geometry as slice geometry plus momentum-like data, constrained by the same physics in a different language.
  • Initial data consists of spatial geometry plus momentum-like change data that obeys Hamiltonian and momentum constraints.
