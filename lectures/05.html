Lecture 05: Lecture 5: Tangent Spaces

How does this lecture use Tangent Spaces and Fields, Dual Vectors Measure Directions, Tangent Vectors As Derivatives to move the course from everyday geometric intuition toward a usable theory of gravity and light?

Family Role

Build space before measuring it: A theory of gravity cannot begin by assuming a fixed grid, fixed rulers, or a surrounding room. These lectures build the minimum language needed to speak about places, change, and physical quantities before distance has been granted.

First-Principles Role

This lecture gives direction an internal meaning. A tangent vector is understood through rates of change of functions, which lets the course talk about velocity, light direction, and local motion without an outside drawing space.

Starting Problem

Tangent spaces are needed because a direction at a point cannot be defined by an arrow drawn in an outside room. Spacetime is not presented as a surface embedded in a larger flat container. The lecture therefore asks what a direction means from inside the manifold. The answer is operational: a direction is known by the rates of change it gives to functions at the point. That makes velocity and light direction local before any global picture is available.

Mathematical Turn

The mathematical turn is to define tangent vectors by their action on test functions. Choose a function near the point and ask how fast it changes along a possible curve through the point. Curves that give the same rate for every test function define the same tangent vector. This shifts direction from picture to operation, which is why later vector fields, observer velocities, and null directions can be defined intrinsically.

Worked Path Through The Lecture

  1. Begin with a point where a direction is needed but no outside arrow is allowed.
  2. Choose local functions that can test movement through that point.
  3. Define the direction by the rate it assigns to each test function.
  4. Collect all such directions at the point into the tangent space.

Objects To Track

  • A tangent space is the vector space of directions available at one point; a field assigns a value, such as a vector or tensor, to each point.
  • A dual vector, also called a covector or one-form, is a linear measuring rule on vectors.
  • A tangent vector can be understood as a rule that tells how functions change at a point along a possible direction.

Linked Concepts

Tangent Spaces and Fields

You need to describe motion at each event in spacetime—what direction a particle could move next. You also need to assign local measurements like temperature or field strength to every point. Without a language for "possible next steps" and "point-by-point quantities," physics has no way to express local physics.

Object: A tangent space at one point is the set of all infinitesimal directions you can move, built from how functions change along possible curves. A field assigns a number, vector, or tensor to every point, smoothly so nearby values stay close to each other.

Operation: Follow a curve through spacetime. At each point, the tangent vector to that curve is its local direction. Differentiate any smooth function (temperature, height, pressure) along that tangent direction: you get the rate of change. Repeat at every point across spacetime and you have a working field operation.

Dual Vectors Measure Directions

In physics, some quantities are arrows (velocity, force, direction of motion) and some are measuring tools (pressure, temperature gradient, intensity of light). The course needs to distinguish them—they transform differently under coordinate changes, and mixing them breaks the math.

Object: A dual vector—also called a covector or one-form—is a linear measuring device on vectors. Think of it as a machine: you feed in a vector, and out comes a single number. The machine respects linearity: if you double the vector input, the output doubles. The key is that this machine changes its internal weights when you change coordinates, in a specific conjugate way that keeps the output stable.

Operation: To use a dual vector, you feed a vector into it and perform a dot-product-like sum. If the dual vector has components (a₁, a₂, a₃) and the vector has components (v₁, v₂, v₃), you compute a₁v₁ + a₂v₂ + a₃v₃. The result is a number that does not depend on which coordinate system you chose to write down the components.

Tangent Vectors As Derivatives

You stand on a hillside and want to measure how temperature changes as you step in one direction versus another. But what exactly is 'a direction at a point'? Spacetime isn't sitting inside a flat container where you can draw arrows from the outside. You need a way to define direction that lives *within* the space itself.

Object: A tangent vector is a rule: a machine that eats any smooth function on the manifold and spits out a number—the rate at which that function changes along a specific direction at that point. It's intrinsic to the space, not an external arrow. The machine encodes both the point and the direction purely through how it interrogates functions.

Operation: To use a tangent vector, you hand it a smooth function (say, temperature T on the manifold). The tangent vector tells you dT along its direction. You can test the tangent vector by checking how it acts on many different functions—always at the same point, always respecting the linearity rule: if you feed it a sum, you get the sum of the answers.
