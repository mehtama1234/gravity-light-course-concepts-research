Lecture 01: Lecture 1: Topology

How does this lecture use Topology and Continuity, Open Sets As Neighborhood Tests, Continuous Maps Preserve Nearness to move the course from everyday geometric intuition toward a usable theory of gravity and light?

Family Role

Build space before measuring it: A theory of gravity cannot begin by assuming a fixed grid, fixed rulers, or a surrounding room. These lectures build the minimum language needed to speak about places, change, and physical quantities before distance has been granted.

First-Principles Role

Lecture 01 should be read as a step in the course's construction, not as an isolated topic. The ordinary problem is: Before measuring distance, the course needs a way to say which points are near enough for a limiting process to make sense. The first lecture needs a way to test whether a small move stays inside an allowed region before it has any distance formula. The course needs a way to say one description respects nearness in another description. The mathematical work to watch is: The basic operation is checking whether inverse images of open sets are open, which is the coordinate-free test that a map preserves nearness. The operation is to ask whether a point has a neighborhood contained inside the region, then use that test to define continuity. The operation is pulling an open test region backward through the map and checking whether it remains an open test region. A good writeup should make that operation visible before using later terms from relativity.

Objects To Track

  • A topology is a chosen collection of open sets: enough information to talk about neighborhoods, limits, and continuous maps without yet talking about meters or seconds.
  • An open set is a region that contains a little breathing room around each of its points, stated without choosing units of length.
  • A continuous map is a rule between spaces whose inverse image of any open region is open in the starting space.
