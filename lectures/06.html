Lecture 06: Lecture 6: Fields

How does this lecture use Tangent Spaces and Fields, Vector Fields As Local Instructions to move the course from everyday geometric intuition toward a usable theory of gravity and light?

Family Role

Build space before measuring it: A theory of gravity cannot begin by assuming a fixed grid, fixed rulers, or a surrounding room. These lectures build the minimum language needed to speak about places, change, and physical quantities before distance has been granted.

First-Principles Role

Lecture 06 should be read as a step in the course's construction, not as an isolated topic. The ordinary problem is: The course needs a way to attach possible directions of motion to every event, then let physical quantities vary from event to event. The course needs a way to assign a possible motion or instruction at every event in a region. The mathematical work to watch is: The basic operation is differentiating a function along a tangent direction and then doing this smoothly point by point across the manifold. The operation is following the assigned directions to form flow lines or using the field to differentiate other quantities. A good writeup should make that operation visible before using later terms from relativity.

Starting Problem

This lecture starts from a concrete obstruction: The course needs a way to attach possible directions of motion to every event, then let physical quantities vary from event to event. It should not be read as a lecture about terminology. The tempting starting picture is: One might imagine every tangent vector as a small arrow drawn in a surrounding Euclidean space. The lecture uses Tangent Spaces and Fields, Vector Fields As Local Instructions to replace that picture with a more careful construction. The reader's job is to notice what has to be built before the later gravity statement is allowed: a kind of nearness, a local naming rule, a slot-aware object, a comparison rule, a measurement rule, or a source accounting rule. The point is to make the hidden assumption visible before any formal expression is trusted.

Mathematical Turn

The mathematical turn is to choose the right object and then perform the operation that tests it. For this lecture the first object is: A tangent space is the vector space of directions available at one point; a field assigns a value, such as a vector or tensor, to each point. The first operation is: The basic operation is differentiating a function along a tangent direction and then doing this smoothly point by point across the manifold. The next linked idea, Vector Fields As Local Instructions, keeps the same pressure by asking whether the statement survives a change of chart, basis, observer, path, or local test. By the time the lecture reaches Vector Fields As Local Instructions, the reader should be able to say what is being acted on, what operation is legal, and what would break if the operation depended on a preferred drawing.

Worked Path Through The Lecture

  1. Begin with the everyday problem: The course needs a way to attach possible directions of motion to every event, then let physical quantities vary from event to event.
  2. Reject the naive picture: Spacetime has no required outside drawing board. Tangent directions must be defined internally by how functions change along possible motions.
  3. Name the object that carries the idea: A tangent space is the vector space of directions available at one point; a field assigns a value, such as a vector or tensor, to each point.
  4. Perform the operation that makes the idea usable: The basic operation is differentiating a function along a tangent direction and then doing this smoothly point by point across the manifold.
  5. Connect it forward through Vector Fields As Local Instructions: Observers, matter flows, and symmetry directions are all described through fields that vary across spacetime.
