Tangent Spaces and Fields

The course needs a way to attach possible directions of motion to every event, then let physical quantities vary from event to event.

Naive Picture

One might imagine every tangent vector as a small arrow drawn in a surrounding Euclidean space.

Why It Fails

Spacetime has no required outside drawing board. Tangent directions must be defined internally by how functions change along possible motions.

Mathematical Object

A tangent space is the vector space of directions available at one point; a field assigns a value, such as a vector or tensor, to each point.

Operation

The basic operation is differentiating a function along a tangent direction and then doing this smoothly point by point across the manifold.

Why It Matters

Particles follow tangent directions, light has null tangent directions, and matter/gravity fields are pointwise assignments over spacetime.

What Breaks Without It

Without tangent spaces and fields, there is no intrinsic way to say velocity, acceleration, local measurement, or local law.

Mini Example

On a hiking trail, your possible next steps at one spot are local directions, while wind speed at every spot is a field. Neither requires the whole mountain to be flattened.

Common Confusion

A field is not automatically a force. It is any smoothly assigned quantity; the kind of field depends on what is assigned.

First-Principles Walkthrough

Start with the ordinary problem: The course needs a way to attach possible directions of motion to every event, then let physical quantities vary from event to event. The tempting shortcut is this: One might imagine every tangent vector as a small arrow drawn in a surrounding Euclidean space. That shortcut fails because Spacetime has no required outside drawing board. Tangent directions must be defined internally by how functions change along possible motions. So the course introduces a specific object instead of a vague picture: A tangent space is the vector space of directions available at one point; a field assigns a value, such as a vector or tensor, to each point. The point is not to admire the object. The point is to perform a controlled operation on it: The basic operation is differentiating a function along a tangent direction and then doing this smoothly point by point across the manifold. Once that operation is available, the later gravity-and-light argument has a stable step to stand on.

Mathematical Detail In Plain Language

The mathematical principle is that a physical claim should name what is being held fixed, what is being changed, and what comparison is allowed. For tangent spaces and fields, the held object is: A tangent space is the vector space of directions available at one point; a field assigns a value, such as a vector or tensor, to each point. The permitted action is: The basic operation is differentiating a function along a tangent direction and then doing this smoothly point by point across the manifold. This matters because the course repeatedly moves from local descriptions to statements that must survive a change of coordinates, observer, or path. Without that discipline, a calculation can report a feature of the chosen description while pretending it has found a feature of spacetime.

Why This Cannot Be Skipped

This concept is critical for the course because Particles follow tangent directions, light has null tangent directions, and matter/gravity fields are pointwise assignments over spacetime. If it is skipped or reduced to a slogan, this is what breaks: Without tangent spaces and fields, there is no intrinsic way to say velocity, acceleration, local measurement, or local law. The practical test is whether a student can explain both the object and the operation in everyday language, then say why the next lecture needs them. That is the level needed for gravity, light, curvature, matter, horizons, waves, and detectors to feel like one chain rather than separate topics.

Tutorial Pressure Tests

Tutorial 5: Tangent Spaces

Pressure test: Use a tangent vector by letting it act on functions. The tutorial pressure is to stop relying on a drawn arrow outside the manifold and instead ask what directional rate the vector assigns to each local function.

Why it changes this concept: This makes tangent space internal. Motion, light direction, and observer velocity can now be explained without borrowing a surrounding flat space, because the direction is known by what it does at the point. That also prepares the later field picture: a field is built from these local actions point by point.

The selected span states that a tangent vector maps a function on the manifold to a real number. That sentence is the reason the page avoids the little-arrow picture as the main explanation. A direction is understood by the rates it gives to functions, which makes tangent vectors internal to the manifold rather than imported from an outside space.

Tutorial 6: Fields

Pressure test: Build a field through bundle language: base, total space, projection, fiber, and section. The tutorial pressure is to make a field choose one allowed object above each base point, then check that projecting it back returns the point it came from.

Why it changes this concept: This changes fields from a vague substance picture into pointwise assignment with bookkeeping. It explains why vector fields, tensor fields, matter fields, and observer fields all need a bundle-level home before they can be differentiated or compared.

The manual span is the definition check: base space, total space, projection, fiber, and section. That is why the page does not describe a field as something poured over space. It describes a field as a section, a rule choosing one allowed object upstairs over each point downstairs while the projection returns the point it came from.
