# Manual Notes Workflow

Use this folder only when YouTube captions and external notes do not support a lecture concept.

Manual notes must be based on watching the lecture video. Do not promote a concept from `missing-transcript` to `manual-notes-backed` from memory, generic textbook knowledge, or a nearby lecture. The note must record the video time span, what is said or written there, and how it supports the concept.

## Required Fields

Each manual note file must include:

- lecture number and title
- video URL
- watched date
- note taker
- timestamp spans
- concise observation from the lecture
- concept ids supported
- object introduced
- operation performed
- why it matters for gravity and light
- what breaks without it
- caveat about uncertainty

Until those fields are filled from actual viewing, the atlas must keep the evidence as unsupported.
